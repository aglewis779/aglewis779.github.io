Privacy policy

AdamOS · last updated 28.10.2026 (2026-10-28)

Who uses it

AdamOS has exactly one user: the person who built it. It does not accept other users.

What it accesses

With the owner's consent through Google sign-in, AdamOS accesses the owner's own Google account: Calendar events, Contacts, Gmail messages, labels and filters, and YouTube playlists.

How the data is used

  • Only to run the owner's personal automations (reminders, calendar and contact sync, email sorting, saving videos from the owner's own playlists).
  • Data is processed on a private server controlled by the owner and is never sold, shared with third parties, or used for advertising.
  • AdamOS's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and deletion

Sign-in tokens are stored only on the owner's private server. Access can be revoked at any time at myaccount.google.com/permissions, which stops all access immediately.

Contact

Questions: use the support email shown on the AdamOS Google sign-in screen.
